# Blue Mobile

نظام إدارة مبيعات كروت الرصيد وإصدار الوصولات، مبني باستخدام React + Vite + Supabase.

## تشغيل المشروع
1. ثبّت Node.js 20 أو أحدث.
2. نفّذ `npm install`.
3. انسخ `.env.example` إلى `.env`.
4. أضف متغيري Supabase في بيئة التشغيل.
5. نفّذ `npm run dev` للتشغيل المحلي أو `npm run build` للبناء.

## إعداد المدير
1. افتح مشروع Supabase: https://supabase.com/dashboard/project/dxkahgaizmtlgihnhmya
2. من Authentication > Users أنشئ مستخدم المدير ببريد وكلمة مرور.
3. افتح بيانات المستخدم وعدّل App Metadata (وليس User Metadata) بإضافة:
   `{ "role": "admin" }`
4. سجّل الدخول من الموقع ببريد المدير وكلمة مروره.

سياسات قاعدة البيانات تعتمد على `app_metadata.role = admin`، ولا تسمح للزوار المجهولين بالوصول إلى سجل المبيعات.

## النشر على Netlify
- Build command: `npm run build`
- Publish directory: `dist`
- أضف `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY` في إعدادات Netlify.

## الوظائف
- لوحة مؤشرات المبيعات.
- بيع كروت ليبيانا والمدار وLTT بقيم 5/10/20/30/50.
- حفظ المبيعات واسترجاعها من Supabase.
- وصل قابل للطباعة الحرارية (80mm) والحفظ PDF من نافذة الطباعة.
- مشاركة بيانات الوصل عبر WhatsApp.
- البحث وإعادة طباعة الوصولات.
- تصدير سجل المبيعات إلى CSV.

## تنبيه أمني
الرقم السري للكرت محفوظ في عمود `card_pin` ضمن جدول المبيعات. العمود محمي بصلاحيات المدير لكنه ليس مشفراً على مستوى التطبيق؛ استخدم حساب مدير قويّاً ومحدود الوصول.
